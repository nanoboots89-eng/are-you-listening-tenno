# 그림 넣는 곳

이 폴더에 아래 이름 그대로 PNG 그림을 넣으면, 게임에서 색깔 상자 대신 그 그림이 나옵니다.
없는 그림은 색깔 상자로 그대로 남으니 하나씩 넣어도 됩니다.

| 파일 이름 | 무엇 |
|---|---|
| excalibur.png | 엑스칼리버 |
| mag.png | 매그 |
| volt.png | 볼트 |
| rhino.png | 라이노 |
| lancer.png | 그리너 랜서 |
| butcher.png | 그리너 부처 |
| heavy.png | 그리너 헤비 거너 |
| background.png | 배경 (높이 720, 가로로 반복됨) |

그림 만들 때 팁
- 캐릭터는 **위에서 살짝 내려다본, 오른쪽을 보고 서 있는 전신**, 배경은 **투명**(PNG)으로 만들어 주세요. 왼쪽을 볼 때는 게임이 알아서 뒤집습니다.
- 발이 그림 맨 아래에 닿게 해 주세요. 크기는 게임이 키에 맞춰 자동으로 줄입니다.
- 파일 이름을 바꾸고 싶으면 `src/data.js`의 `image:` 부분을 고치면 됩니다.
