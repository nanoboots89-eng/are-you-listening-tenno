# 내 말 듣고 있니, 텐노? (Are You Listening, Tenno?)

워프레임 세계관을 바탕으로 한 **비공식 팬게임**입니다. Digital Extremes 및 Warframe과 관련이 없으며, 무료로만 배포합니다.

플레이어는 로터스가 되어 텐노 스쿼드를 임무에 보냅니다. 워프레임들은 알아서 싸우고, 로터스는 임무당 3번만 개입할 수 있습니다.

## 지금 상태: 색깔 상자 전투 시험판
- 엑스칼리버·매그·볼트·라이노 4기가 그리너 5웨이브를 막습니다 (실시간 자동전투).
- 워프레임마다 무기 1개 + 능력 2개, 실드/체력/에너지, 쓰러지면 동료가 일으켜 줌.
- 로터스 개입(키보드 1~4): 집중 공격 · 긴급 보급 · 궁극기 발동 · 후퇴.
- 끝나면 결과 보고서(준 피해, 처치, 쓰러짐, 부활).

## 고치는 법
- 숫자(체력, 피해, 웨이브 구성): `src/data.js`
- 그림 넣기: `assets/README.md` 참고 — 정해진 이름의 PNG만 넣으면 상자가 그림으로 바뀝니다.
- 전투 동작: `src/game.js`

## 내 컴퓨터에서 실행
폴더에서 `python -m http.server` 실행 후 브라우저로 http://localhost:8000 접속.
(index.html을 더블클릭하면 그림 불러오기가 막힐 수 있습니다.)

Phaser 3.80.1 (MIT) 사용 — `lib/phaser.min.js`.
